# Am I Invisible? — first editorial concept

Read [the story](story.txt), [the screenplay](script.md),
[publishing description](publishing-description.txt),
[combined description and full screenplay](description.txt), [keywords](keywords.txt) and
[vertical edit plan](short-edit.md).

Maya’s quiet sketches become the physical thread through a story about missed
signals and being noticed. The last shot returns to the empty booth from the
opening, after she has chosen to join Leo and Max. No narrator explains the
lesson. Dialogue is sparse; names in the screenplay are speaker identifiers,
not video overlays. The thumbnail’s empty-chair promise is part of the plot.

This is an assistant-authored first editorial draft, not a hardcoded template
for every run. The app’s new film-concept workflow generates fresh stories from
its own title and description. This package is not a finished video, rig,
composed soundtrack or claim of rendered 1080p/4K quality.

Timing: a 3-minute request gives a preferred 2:15–3:45 range. This draft plans
**3:30, 12 FPS, 2,520 frames**. The frame count is duration × 12, not a minimum.
All frame counts are production budgets; actual rendered frames are unmeasured.


The example now includes [three actual thumbnail choices](thumbnails/README.md),
[planned subtitles](subtitles.srt), [sound cues with story reasons](sound-plan.json),
[a story-structure plan](story-arc.json), [shot/sequence plans](shot-plan.json), and
[a separate sparse screen-text track](screen-text.srt). The screen-text track is
empty because this particular story does not need text overlays. Subtitle times
refer to the planned edit and require retiming after final picture/audio lock.
The three thumbnails were generated with the chat image tool; the optional
Actions image API integration is separately configured and not yet live-tested.

Only the [14-second opening study](../../previews/layered-opening/README.md)
has been animated. This 3:30 package remains a production plan, not a completed film.
