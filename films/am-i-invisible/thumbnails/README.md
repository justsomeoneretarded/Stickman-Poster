# Three thumbnail choices — Am I Invisible?

2. [NO ONE NOTICES](thumbnail-2.png) — the vulnerability of an offered drawing.
3. [DO I MATTER?](thumbnail-3.png) — looking in at a drawing that was saved.

These three images were generated with the chat image tool using the approved
thumbnail as a read-only identity/style reference. They are new files. The
[approved original](../../../designs/day-one-pivot/thumbnail-direction.png) remains
unchanged. These are conceptual thumbnails, not frames from the rendered video;
minor drawing details differ from the planned props. Review before publishing.

Future Actions runs generate fresh story-grounded briefs. Three fresh final
images require enabling thumbnail_images and configuring OPENAI_API_KEY.
The optional API stage is implemented and mocked in tests, but a real API image
call has not been tested because no image API credential is configured here.
