# Complete animated-film renderer qualification

[Watch the landscape film](long-form/final.mp4) · [Watch the standalone portrait adaptation](short-form/final.mp4) · [Three film-art thumbnails](thumbnails/)

The complete landscape movie is 3:29.25, 1920×1080, 12 FPS, 2,511 rendered frames.
The portrait movie is 1:00, 1080×1920, 12 FPS, 720 rendered frames.
Both contain original procedural music/foley and sparse dry cloned Turbo dialogue.
Scripts, combined description files, keywords, actual line-timed subtitles, audio
reports, decoded-frame receipts and the executable shot data are included.

This is an **assistant-authored qualification of the first editorial draft**;
it proves complete multi-minute rendering, audio integration and packaging.
It is not evidence of a successful automatic title-to-film writing run. The
main workflow separately generates its story/directing from the run's title and
brief; its first live run failed during writing and is being requalified.
The scene/action library is finite; some visual details simplify the prose.
Review narrative fidelity, acting, staging and sound before publishing.

The three included thumbnails are original vector film-art posters generated
without an image API. For the approved detailed illustrated options see
[the first film's three illustrated thumbnails](../../films/am-i-invisible/thumbnails/).
The approved concept and original thumbnail PNGs remain unchanged.

ASR reports check wording, not voice similarity/naturalness. The landscape line
“I kept it dry” was transcribed as “I kept the dry” (WER 0.25); the other tested
utterances transcribed exactly. Treat this as a listening-review flag, not a
claim of perfect speech. Technical checks are not artistic certification.
