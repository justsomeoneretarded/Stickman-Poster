# Miniature voiced two-format qualification

This is a small model-written bench-a-car trial, not a three-minute production
video or artistic approval. Source idea: funny feel-good superstrength with a
parking/gym-membership joke and no ethical lecture.

- Landscape: 1280x720, 24 fps, 22.5 seconds.
- Portrait: 720x1280, 24 fps, 29.8 seconds, separately rewritten dialogue and voice.
- Public user-authorized three-speaker profiles, Chatterbox Nano CPU baseline.
- Both versions passed speech-text screening and complete FFmpeg decode.
- Original vector art/poses; not reference footage. Echo/naturalness and visual
  parity with the reference are not qualified by these checks.

The files are uploaded by Generator development checks as a clearly labeled
local qualification artifact. The production workflow takes a fresh idea each
run and generates both formats. All spoken lines in these files were written
by the local language model, from renderable comic-beat prompts.
